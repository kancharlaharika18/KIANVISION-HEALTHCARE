✚ About Smart Healthcare Appointment System

Smart Healthcare Appointment & Management System is a full-stack Django project developed for KIANVISION Internship. It allows patients and doctors to manage appointments easily - Book, View, Cancel, Track History with proper validation.

Full-Stack Django + Python Bangalore

📋 PDF - 10 Features Implementation

1. Patient Registration

Name, Email (unique), Phone, Age, Gender. URL: /register/

2. Doctor Management

Name, Specialization, Experience, Contact. Add via /admin/

3. Search Doctor

Search by name or specialization. URL: /doctors/?q=Cardiology

4. Book Appointment

Patient + Doctor + Date + Time. Duplicate validation.

5. View Appointments

Upcoming Scheduled appointments. URL: /my-appointments/

6. Cancel Appointment

Cancel button -> status Cancelled

7. Appointment Status

Scheduled, Completed, Cancelled, Rescheduled

8. Role-Based System

Admin Dashboard /dashboard/ - counts & recent appointments

9. Input Validation

unique email + unique_together doctor/date/time - no double booking

10. Appointment History

Completed & Cancelled history. URL: /history/

💻 Tech Stack

Python 3.11 Django 5.0 SQLite DB HTML5 + CSS3 ORM - Models Q Search Messages Framework
